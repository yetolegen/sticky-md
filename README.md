# sticky-md

Sticky notes that are markdown files. Always on top.

Notes = plain `.md` in `~/StickyMD`. Open that folder in Obsidian, same notes.

Run: `pythonw stickies.py`. Python stdlib only.

- pin = always on top, put down = normal window
- colors, dark/light, font size, opacity in settings
- live md: headings, bold, italic, strike, code, checklists, links
- shortcuts: Ctrl+B, Ctrl+I, Ctrl+N, Ctrl+W, Ctrl+L

Test: `pytest`
